SentinelAI

A bounded security-observation dashboard built to turn raw HTTP, DNS and IP evidence into understandable reports.

Current scanner version {{ scanner_version }}

What it does

  • Checks HTTPS and common browser security headers.
  • Records one unauthenticated API response without reading its body.
  • Collects bounded exact-name DNS observations.
  • Explains IP address properties without port scanning.
  • Exports saved evidence as Markdown and JSON.

Public safety design

  • Blocks local, private, reserved and special-use web destinations.
  • Revalidates redirect targets and permits only standard web ports.
  • Limits scan frequency and concurrent work.
  • Separates each visitor’s result history.
  • Disables the deliberately vulnerable local lab online.

Engineering

Python 3.12, Flask, Requests, SQLite, Waitress for local use, and Gunicorn in a non-root Docker container on Render.

Regression tests cover scanner bounds, failure handling, output escaping, CSRF/Host checks, report exports, public destination filtering and visitor isolation.

Honest boundaries

SentinelAI makes observations; it does not exploit targets, guess credentials, sweep ports, confirm vulnerabilities or prove that a system is secure.

Only systems owned by the operator or covered by explicit authorization should be assessed.
