Know what each assessment covers

Website checks HTTPS and common headers. API observes one unauthenticated GET. Domain reads DNS records for an exact name. IP explains address flags, with an optional reverse-DNS lookup.

Observations are evidence to review, not proof that a system is secure. No exploitation, credential guessing or port sweeps are performed.
