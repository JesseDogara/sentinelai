## LinkedIn launch post

I have deployed SentinelAI, my cybersecurity learning project, as a free public beta.

SentinelAI performs bounded observations for websites, APIs, domains and IP addresses,
then turns the evidence into readable results that can be exported as Markdown or JSON.

Preparing it for public access involved more than putting Flask online. I added a
Gunicorn production server, public-destination and redirect validation, CSRF and Host
protection, rate and concurrency limits, secure browser headers, session-isolated
results, a health endpoint and a portfolio page. The public release passed 29
regression tests, dependency auditing and static security analysis.

It is intentionally limited: SentinelAI does not exploit targets, guess credentials,
sweep ports, confirm vulnerabilities or claim that a system is secure. It also does
not currently use an AI model.

The next goal is to learn from genuine users before building accounts or payments.
If you own a website or have explicit authorization to assess one, you can try the
beta and share usability feedback—without posting private targets or confidential
results.

Live beta: https://sentinelai-vn61.onrender.com
